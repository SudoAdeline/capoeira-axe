# Session Notes — March 10, 2026

## 9 Major Feature Updates

### 1. Multi-select Event Types
- Event submission form now uses checkboxes instead of a dropdown
- Multiple types can be selected (e.g. "roda,workshop")
- Stored as comma-separated TEXT in DB
- EventCard and EventDetail show multiple type badges

### 2. Rich Text Price Info
- Price info field changed from single-line input to textarea (3 rows)
- Allows detailed pricing breakdowns

### 3. Auto-hide Past Events
- Home page query now filters out events where `start_date` is in the past
- Admin dashboard still shows all events regardless of date

### 4. Multi-day Locations
- New "This event has multiple locations" toggle on submit form
- Structured form: date + venue + address + city per day
- Stored as `day_locations` JSONB array
- EventDetail renders day-by-day location cards with individual map links

### 5. Featured Teachers / Mestres
- New repeatable section on submit form: name + title + group
- Stored as `guests` JSONB array
- EventDetail shows guest list with avatars
- EventCard shows first 1-2 guest names as preview

### 6. Phone / WhatsApp Contact
- New `contact_phone` field on submit form
- EventDetail shows phone number + WhatsApp link (if number starts with +)

### 7. Registration Deadline + Link
- Optional deadline datetime + external registration URL
- EventDetail shows deadline, "Register" button, or "Registration closed"

### 8. Event Schedule / Program
- Repeatable time + description entries
- Stored as `schedule` JSONB array
- EventDetail renders as vertical timeline

### 9. Organizer Role System
- Signup form has "I am an event organizer" checkbox with ? tooltip
- Checking it sets `organizer_status: 'pending'` in profiles
- Admin dashboard has "Organizer Requests" tab to approve/reject
- Only approved organizers (and admins) see "Submit Event" in nav
- Non-organizers cannot access the submit page at all

## Other Changes

### Delete Account in Profile Menu
- Added "Delete Account" link in the profile dropdown menu
- Links to existing `/delete-account` page

### Delete Account Auto-redirect
- Success screen now auto-redirects to home after 3 seconds
- Added a manual "Back" button as well

## Database Migration (003_app_updates.sql)
Run in Supabase SQL editor:
```sql
ALTER TABLE events ADD COLUMN IF NOT EXISTS day_locations JSONB;
ALTER TABLE events ADD COLUMN IF NOT EXISTS guests JSONB;
ALTER TABLE events ADD COLUMN IF NOT EXISTS contact_phone TEXT;
ALTER TABLE events ADD COLUMN IF NOT EXISTS registration_deadline TIMESTAMPTZ;
ALTER TABLE events ADD COLUMN IF NOT EXISTS registration_url TEXT;
ALTER TABLE events ADD COLUMN IF NOT EXISTS schedule JSONB;
ALTER TABLE profiles ADD COLUMN IF NOT EXISTS organizer_status TEXT DEFAULT NULL;
```
